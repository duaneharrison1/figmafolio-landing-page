A site made from a Figma prototype only works if anyone with the link can open that prototype. Until now it was easy to publish one that visitors could not see.

Now, under each link field, Figmafolio checks the link as a visitor would:

- A green line says anyone with the link can open it.
- A red box says visitors can't open it yet, with **Show me how** and **Check again** buttons.
- Show me how opens a short guide to Share, Anyone, View and Copy link. It re-checks every few seconds and closes when the link works.

If you paste a design, file or branch link, Figmafolio changes it into a prototype link and tells you.

On 13 November the dashboard started warning on site tiles too, with a **Fix sharing** button, for sites whose prototype is not shared. This catches older sites, or ones where sharing was changed in Figma later.

Saving and previewing are never blocked by the check. If the check cannot run, it shows nothing.

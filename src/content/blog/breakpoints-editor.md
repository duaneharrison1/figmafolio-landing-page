The screen size editor in your site settings changed.

- A new site shows one row, **All screens**.
- **Add breakpoint** lets you add Phone, Tablet, Large desktop or a custom width, up to 6 rows.
- A row with no link of its own says **Same as Desktop**. A row with its own link has a **Reset** button.
- Rows run from the biggest screen to the smallest. A width can be used once.
- "Mobile" now reads "Phone". Names already saved are unchanged.

Adding a tablet row does not change what visitors see until you paste a link for it.

See [desktop and mobile on one link](/features/responsive-design).
